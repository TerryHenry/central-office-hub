Quick Start

Central Office Hub

From a fresh VM to your first managed site, in six steps.

HardwareAny VM (VMware, VirtualBox, Proxmox, ESXi) or bare Linux host
OSDebian 12 (bookworm) or compatible, amd64
FleetOne or more Serial Killer Terminal Server appliances to enroll
NetworkReachable from every site you plan to enroll

  1. Deploy the VM

    Import the central-office-hub.ova appliance into your hypervisor (VMware Fusion/Workstation/ESXi, VirtualBox, or Proxmox), attaching your own cloud-init seed for SSH key, password, and hostname — it ships with no OS-level login baked in. The app itself starts on boot regardless of that configuration.

    Installing on an existing host instead?

    Run provisioning/setup.sh on any Debian-based Linux host to install alongside whatever else is already there — see the project README.

  2. Log in to the admin UI

    Visit https://<vm-ip>:8443 (accept the self-signed certificate warning) and sign in with admin / letmein0!.

    First login

    You'll be required to set a new password immediately — enforced by the server itself.

  3. Generate an enrollment token

    Sites tab → + Generate Token. Copy the token it shows you.

  4. Enroll a site

    On the appliance itself: Server tab → Central Office (Fleet) → switch to Managed → paste the token into Enroll with a token → Enroll. The site appears on this hub's Sites tab within moments, reporting its ports automatically.

  5. Create a group and grant access

    Groups tab → + Add Group → check the ports it should grant, choosing read-write or read-only per port → Save.

  6. Add a console user and connect

    Users tab → + Add User → set a password and assign the group you just created → Save. From any machine on the network:

    ssh -p 2222 <username>@<hub-host>

    The port menu lists exactly what that user's groups grant — nothing more.

That's the essentials.

For access permissions, session capture, syslog forwarding, backup/restore, and everything else, see the full Handbook.
