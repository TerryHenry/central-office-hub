Tunnel / SSH Listener

        
The single port every enrolled site's tunnel connects to, and that an admin-tunnel SSH session also uses -- default 443 (chosen so an edge site's outbound firewall almost never needs a new rule for it), but changeable if this network needs something else.

        

          
          
        

        

          
        

        
Takes effect only after a restart (the TLS Certificate panel's Restart Service Now, further down this tab) -- saving alone doesn't rebind the listener. Once it restarts, every currently-connected site's tunnel drops immediately and won't be able to reconnect until that site's own Central Office panel has its Tunnel Port updated to match this new value -- this is a fleet-wide change, not a hub-only one.

        

      


      

        
High Availability

        
Configures the standalone ha-agent process on THIS node only -- the peer node needs its own matching configuration with role/host swapped. Saving writes ha-agent/config.json and, if the agent is already running here, tells it to reload live. A brand-new agent still needs its systemd service started once by hand -- see the README's "High Availability" section.
